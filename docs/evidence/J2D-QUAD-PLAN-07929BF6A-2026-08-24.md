## Fixture contract

The new path encodes four XYZ/F32 positions and four logical RGBA8 colors as
direct canonical Geometry attributes. It requires:

- primitive `GX_QUADS`, vertex format 0, and vertex count 4;
- present attributes `POS|CLR0` and normalized plan components Position and
  Color0;
- one disabled `COLOR0A0` record with REG ambient source, VTX material source,
  diffuse none, and attenuation none;
- zero active Texgens while retaining source-valid dormant matrix metadata;
- null TEV texture coordinate and texture map, with color channel 0;
- no required Texture or Dynamic resource; and
- effective logical position matrix 0 and zero texture-matrix selectors for
  every decoded vertex.

The test checks all four position/color values, the plan masks and counts, the
channel/Texgen/Texture/Dynamic/TEV fields, and input immutability on success.
Its negative control mutates only the primitive to a four-vertex TRIANGLES
batch, expects `ACGC_APPLE_CANONICAL_PLAN_GEOMETRY_LIMIT`, and reuses the
existing helper that proves both envelope and destination remain byte-for-byte
unchanged on failure.

The fixture does not claim that this is the complete state used by every J2D
draw. In particular it does not exercise the production consumer, viewport,
scissor, depth, raster line width, TEV PASSCLR behavior, or any Texture-backed
font path.

- `src/static/JSystem/J2DGraph/J2DGrafContext.cpp::setup2D` for cleared VCD,
  direct Position/Color0, disabled Tex0, zero active Texgens, null texture
  order, and disabled REG/VTX channel state;

  Position/Color0 vertices emitted as `GX_QUADS`;
- `src/static/JSystem/J2DGraph/J2DOrthoGraph.cpp` for position matrix 0; and
- `src/static/dolphin/gx/GXGeometry.c` plus `GXTransform.c` for primitive,
  count, and matrix-load semantics.

The host canonical envelope and Apple value plan have no direct decomp
counterpart. The decomp paths establish only the source behavior represented
